# YOLO RPI HAILO Implementation Messages Documentation

## Overview

This document details all DroneEngage protocol messages handled and generated by the RPI HAILO YOLO AI implementation. This implementation runs on Raspberry Pi with HAILO AI accelerator hardware.

## Message Types

### Input Messages (Handled by Parser)

#### 1. TYPE_AndruavMessage_AI_Recognition_ACTION (1076)
**Purpose**: Commands to control AI recognition functionality

**Message Structure**:
```json
{
  "mt": 1076,
  "ms": {
    "a": <action_id>,
    "i": [<class_indices>]  // Optional, for SEARCH action only
  }
}
```

**Supported Actions**:

| Action ID | Action Name | Description | Parameters |
|-----------|-------------|-------------|------------|
| 1 | `TrackingTarget_ACTION_AI_Recognition_SEARCH` | Start tracking specified object classes | `i`: Array of class indices to track |
| 2 | `TrackingTarget_ACTION_AI_Recognition_DISABLE` | Disable AI recognition tracking | None |
| 3 | `TrackingTarget_ACTION_AI_Recognition_ENABLE` | Enable AI recognition tracking | None |
| 4 | `TrackingTarget_ACTION_AI_Recognition_CLASS_LIST` | Request list of available classes | None |

**Parser Location**: `yolo_ai_parser.cpp` - `parseMessage()` method

#### 2. TYPE_AndruavMessage_RemoteExecute (1005)
**Purpose**: Execute remote commands on the module

**Message Structure**:
```json
{
  "mt": 1005,
  "ms": {
    "C": <command_id>
  }
}
```

**Current Implementation**: No specific remote commands implemented (placeholder for future expansion)

**Parser Location**: `yolo_ai_parser.cpp` - `parseRemoteExecute()` method

---

### Output Messages (Generated by Facade)

#### 1. TYPE_AndruavMessage_AI_Recognition_TargetLocation (1078)
**Purpose**: Send detected object locations

**Message Structure**:
```json
{
  "mt": 1078,
  "ms": {
    "t": <targets_data>     // All detected targets
  }
}
```

OR

```json
{
  "mt": 1078,
  "ms": {
    "b": <targets_data>     // Best/targeted object
  }
}
```

**Generated By**:
- `sendTrackingTargetsLocation()` - Sends all detected objects
- `sendTrackingBestTargetsLocation()` - Sends best/targeted object

**Facade Location**: `yolo_ai_facade.cpp`

#### 2. TYPE_AndruavMessage_AI_Recognition_STATUS (1077)
**Purpose**: Send AI recognition status information

**Message Structure** (Class List Response):
```json
{
  "mt": 1077,
  "ms": {
    "a": 4,  // TrackingTarget_STATUS_AI_Recognition_CLASS_LIST
    "c": [<class_names>]  // Array of available class names
  }
}
```

**Message Structure** (Status Updates):
```json
{
  "mt": 1077,
  "ms": {
    "a": <status_code>
  }
}
```

**Status Codes**:
- 0: `TrackingTarget_STATUS_AI_Recognition_LOST`
- 1: `TrackingTarget_STATUS_AI_Recognition_DETECTED`
- 2: `TrackingTarget_STATUS_AI_Recognition_ENABLED`
- 3: `TrackingTarget_STATUS_AI_Recognition_DISABLED`
- 4: `TrackingTarget_STATUS_AI_Recognition_CLASS_LIST`

**Generated By**:
- `sendTrackingClassesList()` - Responds to CLASS_LIST action
- `sendTrackingTargetStatus()` - Sends status updates

**Facade Location**: `yolo_ai_facade.cpp`

## Message Flow Diagrams

### AI Recognition Control Flow
```
GCS/Controller → YOLO Module
├── ACTION (1076) - SEARCH with class indices
│   └── Response: TargetLocation (1078) with detected objects
├── ACTION (1076) - ENABLE
│   └── Response: STATUS (1077) with ENABLED status
├── ACTION (1076) - DISABLE
│   └── Response: STATUS (1077) with DISABLED status
└── ACTION (1076) - CLASS_LIST
    └── Response: STATUS (1077) with class list
```

### Continuous Detection Flow
```
YOLO Module → GCS/Controller
├── TargetLocation (1078) - "t" field: All detected objects
└── TargetLocation (1078) - "b" field: Best/targeted object
```

## Implementation Files

### Parser (`yolo_ai_parser.cpp`)
- **Input**: Handles ACTION and RemoteExecute messages
- **Architecture**: Standalone parser class (no base class inheritance)
- **Methods**: `parseMessage()`, `parseRemoteExecute()`
- **Validation**: Uses `validateField()` helper method

### Facade (`yolo_ai_facade.cpp`)
- **Output**: Generates TargetLocation and STATUS messages
- **Inheritance**: Extends `de::comm::CFacade_Base`
- **Methods**: `sendTrackingTargetsLocation()`, `sendTrackingBestTargetsLocation()`, `sendTrackingClassesList()`, `sendTrackingTargetStatus()`
